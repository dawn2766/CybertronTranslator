## Faction insignia

### `autobot-logo.png`

- Reference file: https://en.wikipedia.org/wiki/File:Autobot_logo.png
- Local source copy: `autobot-logo-source.png`
- UI treatment: extracted the visible subject, normalized it to Autobot red (`#e52d39`), and centered it on a 320 x 320 transparent canvas with a 280 px subject height.

### `decepticon-logo.png`

- Reference file: https://en.wikipedia.org/wiki/File:Decepticon_logo.png
- Local source copy: `decepticon-logo-source.png`
- UI treatment: extracted the visible subject, normalized it to Decepticon purple (`#8f53c4`), and centered it on a 320 x 320 transparent canvas with a 280 px subject height.

The in-app composite and all install icons place both normalized insignia in the same square target rectangle. Each insignia keeps its natural aspect ratio; the left half is Decepticon and the right half is Autobot.

The faction insignia are copyrighted franchise marks. The source files are recorded as non-free fair-use logo references by Wikipedia and are used here only as identifying elements in a Transformers-themed interface.
