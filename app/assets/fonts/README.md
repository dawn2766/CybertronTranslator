# Cybertron Browser Fonts

`cybertron-autobot.woff2` and `cybertron-decepticon.woff2` are the two browser
fonts bundled with the PWA. Uppercase and lowercase Latin letters map to the
same 26 family glyphs stored under `../glyphs/`.

Punctuation in the translated output uses the local `Bahnschrift` DIN-style
font when available. `gidole-latin-400-normal.woff2` provides the bundled
fallback for browsers without it. Gidole is based on DIN 1451, the same design
tradition as Bahnschrift. It comes from `@fontsource/gidole` and is licensed
under the SIL Open Font License 1.1; see `GIDOLE-OFL.txt`.
